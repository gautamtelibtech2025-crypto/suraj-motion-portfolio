# Suraj portfolio site

Interactive sketch-style portfolio for Suraj, a short-form video editor and motion designer.

## Run locally

```bash
npm install
npm run dev
```

The showreel is bundled locally at `public/media/showreel.mp4` so it plays reliably in the browser. Project source clips and the full archive use the public Google Drive folder:

https://drive.google.com/drive/folders/1KXnLnY_tfjyHWIlzmoqhhisAoNom1CjG

## Included

- Paper preloader with hand-drawn portfolio scene and door transition
- Ambient music toggle with original Web Audio loop
- Local showreel video modal with autoplay and native controls
- Filterable work grid
- Project detail overlays with role, software, gallery, and source clip links
- About and contact rooms
- Responsive mobile layout
